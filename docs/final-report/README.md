## Viktigt före inlämning

Varje student ska själv:

1. Kontrollera och anpassa KPI-motiveringar och slutsatser.
2. Fylla i markerade fält om sitt eget bidrag och lärande.
3. Länka till egna commits, issues eller pull requests.
4. Commit:a ändringarna med sitt eget GitHub-konto.
5. Kontrollera att inga hemligheter finns i filerna.

Texterna är startunderlag. Oförändrade kopior visar inte individuell analys.
